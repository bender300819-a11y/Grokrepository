# Risha Companion

AI-компаньон «Риша» — персональный помощник и собеседник в стиле персонажа из Star Wars: The Old Republic.

## О проекте

Это кроссплатформенное мобильное приложение, созданное с помощью **Expo (React Native)**.

Цель — собрать готовое приложение, которое можно опубликовать в:
- Google Play
- App Store

## Текущий статус

- Базовая структура проекта создана
- Простой чат-интерфейс с Ришей
- Готово к дальнейшей разработке (подключение ИИ, дизайн, сборка)

## Как запустить

```bash
npm install
npx expo start
```

## Стек

- React Native + Expo
- TypeScript
- Готово к сборке в APK / AAB / IPA
